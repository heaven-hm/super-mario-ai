**Verify ROM (ROM bytes are never committed):**

```bash

```

**Documented Rainbow evaluation (requires FCEUX 2.6.6_12):**

```bash
PYTHONPATH=python python3 -m mario_ai_fceux.evaluate --rom /path/to/SuperMarioBros.nes --fceux /opt/homebrew/Cellar/fceux/2.6.6_12/bin/fceux --run-dir runs/drift-20261003/drift-study/pin-004 --world 1 --episodes 20 --evaluation-seed 2026 --device cpu
```

**Regenerate this report (offline, no emulator):**

```bash
bash scripts/regenerate_benchmark_report.sh
```

```bash
FCEUX_LUA_PROBE_OUTPUT=/tmp/fceux-lua-probe.txt fceux --loadlua "$PWD/scripts/probe_fceux_lua.lua" /path/to/SuperMarioBros.nes ; cat /tmp/fceux-lua-probe.txt
```

## Interpretation limits

- A Wilson interval describes binomial sampling uncertainty only. It does not cover checkpoint selection, emulator differences, or non-deterministic replay interleaving.
- A rate is only comparable across methods when the protocol tuple above matches exactly; the validator refuses mixed reports.
- No full 1-1 clear clip or GIF is claimed here. A clip must come from a recorded winning run on a desktop session; none is present in the repository.
